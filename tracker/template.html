Run a matched pair on the same card, driver and power limit: one normal boot, one unlocked boot. With ada-unlock-kit that is:

  1. python -m adakit bench stock on a normal boot
  2. python -m adakit bench unlocked after booting the stick
  3. python -m adakit report results\result-stock.json results\result-unlocked.json --loader "nv-uefi-unlocker vX"

Paste the entry.json it writes below. The page checks it and opens a GitHub issue with your numbers filled in; attach report.md and chart.png there. Reports go to the ada-unlock-kit issue tracker. Nothing is sent until you submit on GitHub.
